# Anti-slop audit 001

This audit was run after the visual revamp. Findings below document the original issues and their resolution.

1. HIGH, R-02: UI text used em dashes in headings, descriptions, metadata, and navigation labels. Replaced with commas, colons, or sentences.
2. MEDIUM, R-05 / R-14: The page repeatedly used uniform feature and project cards, which flattened the difference between flagship and supporting work. The project presentation now gives the leading case study more space.
3. MEDIUM, R-09 / R-13 / R-19: The hero combined an availability badge, status dot, typewriter cursor, and cursor glow. Removed because none added decision-relevant information.
4. MEDIUM, R-08 / R-15: Decorative arrows appeared beside multiple calls to action. Removed so the action labels carry the meaning.
5. MEDIUM, R-06 / R-20: The previous visual language relied on generic developer-site signals, including monospaced hero treatment and indigo surfaces. The new type, palette, and dossier-like layout are tied to the portfolio's public-service systems work.
6. LOW, R-11 / R-12: Large rounded, floating surfaces were the default component treatment. Cards are now flatter, more structured, and reserve elevation for none.
