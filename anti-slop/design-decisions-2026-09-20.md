# Design Decisions — Modern Digital Systems Portfolio (2026-09-20)

## Direction Summary
A modern, precise, editorial-technical portfolio for a Backend Developer & System Integration Specialist (Ravi Zulfikar / Zivar).
Dial: ENERGY 2 / RHYTHM 3 / MOTION 1.

## Visual & Technical Foundations
- **Aesthetic**: "Modern Digital Systems Portfolio" — technical, fast, architectural, authoritative, and dependable. Avoids cyberpunk tropes, neon washes, AI-slop badges, and generic landing page bento grids.
- **Palette**:
  - Dark Mode: Deep obsidian / graphite navy (`#090d16` canvas, `#0f172a` primary surfaces, `#141e33` elevated panels, `#1e293b` borders).
  - Light Mode: Off-white slate (`#f8fafc` canvas, `#ffffff` primary surfaces, `#f1f5f9` elevated panels, `#e2e8f0` borders).
  - Accent: Precision Electric Cyan / Sky (`#0ea5e9` dark, `#0284c7` light for WCAG AA 4.5:1+ contrast). Used sparingly at key moments of action or status.
  - Success/Status: Emerald (`#10b981`) for live production systems and verified credentials.
- **Typography**:
  - Headings/Display: Plus Jakarta Sans (`var(--font-display)`) — crisp geometric character with modern authority.
  - Body: Inter (`var(--font-sans)`) — standard-bearer for legible technical editorial prose.
  - Technical Metadata: JetBrains Mono (`var(--font-mono)`) — razor-sharp monospace for specs, API routes, command snippets, and telemetry markers.
- **Layout & Rhythm**:
  - Hero: Editorial-technical dossier format with live telemetry metrics (5+ years, 12+ integrated systems, core backend stack), broad professional engineering scope, and high-contrast actions.
  - About: Technical architectural pillars (Reliability, Integrity, Cross-Agency Interoperability) paired with clear narrative context.
  - Skills: Modular system capabilities index with both light and dark mode native styling.
  - Projects: Expansive case-study presentation for the primary flagship work ("Proyek Unggulan" / "Featured Project"), followed by a structured technical index with natural labels ("Kunjungi Website" / "Visit Website") and live/GitHub destinations.
  - Packagist: Open-source distribution index featuring one-click composer terminal commands and package telemetry.
  - Experience & Certifications: Engineering chronology with official government verification markers and BNSP credentials.
  - Contact: Functional direct communication terminal with email copy feedback, UTC+7 timestamp indicator, and contact form.
- **Accessibility & Motion**:
  - Full WCAG AA contrast compliance across both light and dark modes.
  - Strict adherence to `prefers-reduced-motion` via Framer Motion `MotionConfig`.
  - Keyboard focus rings with explicit 2px offset cyan indicators.
